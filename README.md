## Что здесь

Проект изучает данные клиентов обратившихся в поддержку с проблемами доступа к сервису Прайм из учебной базы. В данной выборке 1000 клиентов за апрель-сентябрь 2025 года. Фаил hw1 в папке notebooks считает сколько было обращений по дням, сколько часов уходит в день на клиентов, как нагрузка распределяется по дням и какие дни были пиковыми.
`notebooks/hw1.ipynb` - обращения в поддержку на тему «доступ к сервису»
  за апрель–сентябрь 2025, выборка из 1000 клиентов: сколько обращений решено,
  сколько часов уходит на решение, как нагрузка распределяется по дням недели
  и какие дни были пиковыми.
`notebooks/hw2.ipynb` - витрина клиента по сегменту:
  выручка, цена по справочнику тарифов, CAC по каналам, число людей,
  пользующихся ПРАЙМ, и протокол сборки, который доказывает отсутствие двойного счёта.
- `src/prime/checks.py` - проверки качества данных.

## Как запустить

Нужны [Git](https://git-scm.com/) и [uv](https://docs.astral.sh/uv/).
Python отдельно ставить не нужно — его поставит uv.

```bash
git clone git@github.com:ВАШ_ЛОГИН/prime-monitor.git
cd prime-monitor
uv sync
```

Доступ к учебной базе выдаёт бот курса по команде `/db`. Полученную строку
подключения кладём в `.env`:

```bash
cp .env.example .env
# и вписать в .env строку из бота
```

Проверка, что всё встало:

```bash
uv run python -c "from prime.config import get_engine; print(get_engine().connect().execute(__import__('sqlalchemy').text('select current_user')).scalar())"
```

Запуск JupyterLab:

```bash
uv run jupyter lab
```

## Что здесь считается

| Выручка | сумма `amount` по платежам со статусом `success` за окно |
| Цена по справочнику | Строка 429 ₽ исключена как ошибочная - она перекрывала обе соседние цены |
| Люди | клиенты сегмента, которые владеют подпиской |
| CAC | расходы канала за месяц / число новых клиентов всей базы из канала за этот месяц |
| Витрина клиента | одна строка - один клиент сегмента. Проверяется через: ЗЕРНО, ДЕНЬГИ, ЛЮДИ |
