## Что здесь

Проект изучает данные клиентов обратившихся в поддержку с проблемами доступа к сервису Прайм из учебной базы. В данной выборке 1000 клиентов за апрель-сентябрь 2025 года. Фаил hw1 в папке notebooks считает сколько было обращений по дням, сколько часов уходит в день на клиентов, как нагрузка распределяется по дням и какие дни были пиковыми.

## Как запустить

Нужны [Git](https://git-scm.com/) и [uv](https://docs.astral.sh/uv/).
Python отдельно ставить не нужно — его поставит uv.

```bash
git clone git@github.com:ВАШ_ЛОГИН/prime-monitor.git
cd prime-monitor
uv sync
```

Доступ к учебной базе выдаёт бот курса по команде `/db`. Полученную строку
подключения кладём в `.env`:

```bash
cp .env.example .env
# и вписать в .env строку из бота
```

Проверка, что всё встало:

```bash
uv run python -c "from prime.config import get_engine; print(get_engine().connect().execute(__import__('sqlalchemy').text('select current_user')).scalar())"
```

Запуск JupyterLab:

```bash
uv run jupyter lab
```
