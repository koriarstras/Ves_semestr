## Что я проверил сам

SRM посчитал двумя способами, `stats.chisquare` и своей `srm_pvalue`, оба дают 0,661. Разность средних из `diff_ci` сверил с t-критерием в HypEx, 0,700148 совпало до знака. CUPED пересчитал своей функцией и внутри HypEx, θ, дисперсия и разность совпали. Бутстрепу не поверил на слово и сравнил его интервал с нормальным приближением: 342,46 ₽ против 328,85 ₽ ширины, то есть приближение чуть оптимистичнее. Денежный расчёт пересобрал вручную на калькуляторе по слагаемым: 0,67 + 1,06 − 0,50 = 1,22 ₽. Прогнал ноутбук целиком после Restart Kernel and Run All Cells. По ходу проверки всплыли две мои ошибки, которые я исправил сам: ответ задачи 11 был вписан руками вместо расчёта, и список признаков для мэтчинга создавался ниже ячейки, которая его использует.
